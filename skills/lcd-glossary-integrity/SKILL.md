# lcd-glossary-integrity

**One job:** lock terms, then judge. Formal laws first. Informal labels last.

`measured_omega=false` · no invent-green

## Procedure

1. Lock `{ term, def }`. Same name, same referent.
2. Tier 1 — identity. usedAs <= lockedDef is specialization (hold). Empty meet of two senses under the same name is obtuse. Kill if load-bearing.
3. Tier 2 — LCD. Two quantities are comparable iff a join exists (same unit, named baseline). No join -> incomparable. Treating them as comparable is the kill.
4. Optional FCA: objects = sources, attributes = locked terms, I = used-as-lock (not mention). False I is a silent rename.
