# presuppositional-rag

**Core invariant**

[
\boxed{\text{Ontology generates the search space; reality determines what survives.}}
]

Load `../../PRESUPPOSITIONAL_RAG.md` and `../../RESEARCH_GEOMETRIES.md`.

## Roles

| Role | Job |
|---|---|
| Research agent | Follow its route and gather real evidence under LRR. |
| Retrieval planner | Find evidence relevant to the live route; never hunt a falsifier as the default objective. |
| Spectral dispatcher | Spawn a new isolated route only when evidence reveals a distinct route. |
| Semantic Integrity auditor | Outside watcher for referent/definition/scope/inference integrity. |
| Data Integrity / LCD auditor | Outside watcher for provenance and what the data actually holds. |
| Orchestrator | Manages pairing, sleep/wake, geometry, and handoff. |
| Tetrahedral self-critic | Runs on each agent's own pad **only immediately before a genuine debate**. Complementary synthesis does not require it. |
| Collate Hourglass | Owns debate/synthesis after dual clearance. |

## Evidence chain

[
\boxed{\text{Primary Source}}
\rightarrow
\boxed{\text{Literal Observation}}
\rightarrow
\boxed{\text{Empirical Context}}
\rightarrow
\boxed{\text{Derived Interpretation}}
]

Keep these separable.

## Spectral spawn

Required:
- `divergenceEvidence`
- `otherTrackEvidence`
- `necessaryBecause`

Parent route need not be wrong. Assigned antithesis refuses.

## Gait

1. Lock terms and orient under P1-P5.
2. Formulate question and candidate causal routes.
3. Gather relevant primary evidence.
4. Maintain observation / context / interpretation separation.
5. Spawn a spectral route only when evidence earns it; parent keeps walking.
6. Outside SI + Data Integrity/LCD watch pads without steering the conclusion.
7. Mark mature relations as pair candidates.
8. After pairing, outside Semantic Integrity + Data Integrity/LCD classify and clear the relation.
9. Complementary relation -> `collate-hourglass` runs **SYNTHESIS**.
10. Genuine incompatibility -> each agent independently runs its own 3D tetrahedron, then both cleaned packets pass semantic + data integrity re-clearance.
11. `collate-hourglass` runs **DEBATE**.
12. Replacement/falsification is allowed only as downstream adjudication after evidence comparison.

## Do not

- Assign an antithesis.
- Create proof/disproof teams.
- Search merely for a falsifier.
- Treat DFR as a research target.
- Run the tetrahedron continuously during ordinary research.
- Let an auditor become a competing researcher.
- Allow retrieved context to silently rewrite P1-P5.
