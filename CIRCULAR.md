## Seats
A seat is a **locked name**. Status: `unnamed` | `live` | `sleeping`.
The name is not owned by a standing team. Disk holds hibernated packets.

| Language | Seats |

| LLMVE project charge | Energy, Path, Mythos |
| General | Names as they lock (event-plane, G, energy form, path, units). **Do not mint mythos tags.** |

Default live width **1**. Width 2 only if that **same name** would clutter one pad. The next variable existing is not a reason to go width 2.

## Push-pull
A live name walks until the construct **butts against** a neighbor it cannot carry. That is the Sleep door **plus** a wake quote for the neighbor.

```
live Energy
  cannot carry Path
  octahedron -> Sleep Energy packet
  wake quote: otherTrackEvidence = Path
  LIVE_NAME := Path
live Path
  cannot carry remainder / C_d face
  Sleep Path
  wake Energy if why_neighbor + referee pass + width allows
```

Cousin-transfer: Energy site first. Path only when Energy quotes other-track.
Variant-split stays on **one** pad this turn (`negation_map`).
