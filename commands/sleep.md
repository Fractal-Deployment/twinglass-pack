# /sleep

Use this only after the **live** seat has completed its current layer and the required octahedron/referee step has reached the Sleep door.

Load `RING.md` and `CIRCULAR.md` first. Their current packet/wake rules are authoritative.

## Writer

Write one WORKING packet with the ordinary CLI/workspace file writer at:

```
reports/circular_packets/<seat>.pad.md
```

That file write is the writer. Do **not** hunt for MCP `filesystem_*`, `search_tool`, or another storage owner.

The packet is hibernated working state:
- not court/canon;
- not SemVer;
- not a standing agent/team;
- not an active walker after Sleep.

## Packet fields

Preserve the current `RING.md` contract:


Do not copy the parent transcript. Write the fields and evidence needed to continue the named seat.

## After write

Update the board consistently:

```
LIVE_NAME:
DOOR: sleep
PACKETS: n+1
```

The sleeping packet does not count as a live walker.

## Wake

Wake is a **new empty-history session**. Load packet fields, not transcript history.

A wake requires the current ring conditions:
- `why_neighbor`;
- `otherTrackEvidence` naming the relevant neighboring seat;
- referee clearance that units/axes are comparable;
- width permits the wake;
- where the circular return rule applies, the required new packet quote/digest condition.

No calendar wake. No fill-ten.

- spawn the neighbor merely because Sleep occurred;
- mint authority/canon or SemVer from Sleep;
- change `CAP: 10`;
- take ownership of Meet (still `collate-hourglass`).
