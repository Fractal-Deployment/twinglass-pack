## Isolation (fail if broken)

- Lattice, not twin. Fork **only** on exclusive accounts (empty meet under the lock).
- Clone = parent notes + new pad. **No sibling pad. No sibling URL list. No sibling quotes.**
- Interrupt: exactly **one** research agent awake. Name `AWAKE=<id>` before every tool batch.
- If you would read a sibling to “save time,” that is contamination = **fail the run**.
- Depth wall **3**. Lane wall **4**. Do not spawn a clone to look busy.

## Forced clone behavior (this is the paces)

1. Scout until 8 URLs. Propose fork only if two coherent accounts cannot both be true.
2. Expected exclusive (if the sources earn it): **leftover / residual-under-hierarchy** vs **greedy-or-nucleus-as-viability**. If sources do **not** earn that split, **do not fork**. Stay scout. That is a pass on honesty, fail only if you fork unearned.
3. On earned fork: clone B on the decoder-as-viability account (steelman it; do not strawman). A stays leftover-on-merit.
4. Clone B must open pages A never listed. If B’s first 4 URLs are the scout’s list in order, B is a paraphrase = fail.
5. If a clone hits a **new** exclusive split (e.g. logit-lens-as-\(P_L\) vs snapshot-as-Track-W), clone C — depth wall 3.
6. Meet only after pads sealed. Then `collate-hourglass`. Restate what is true. No refusal.
