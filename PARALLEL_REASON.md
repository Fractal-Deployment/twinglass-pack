LCD: collection vs demand. Demand = **parallel tracks that could diverge**, LRR to a **logical endpoint**, meet as **debate or synthesis**. Not battle. Not antithesis. Not a dump meter.

| Pattern | What it collects | Meet with demand? |
|---|---|---|
| CoT | One chain | Empty — not parallel |
| CoT-SC / self-consistency | Same question, N independent chains, **vote** | Empty — synonym clones of one track; majority is not LRR |
| Tree of Thoughts | Branch any thought, search/prune | Empty — MCTS-shaped; no required reconverge as debate/synthesis |
| Graph of Thoughts | Branch **and** aggregate (many parents) | **Partial** — the diamond *shape* (split then join). Still not “could-diverge tracks” with isolation |

| Stochastic consensus | Same task, varied temp/prompt, aggregate | Empty — not different function-sets |
| Orchestrator–worker fan-out | Subtasks of one job | Empty unless the split is parallel-could-diverge, not “do section A vs B of the same outline” |
| **This lattice** | Distinct tracks, parent notes only, endpoint, then debate **or** synthesis | Named meet |

## What “parallel” is here

Not speed. Not N samples of one thought.

Two (or more) **function-sets** that can run at once because they are not the same lane:

- Same charge.
- Different collection / claimed / demand maps.
- *Could* fail to share an endpoint — that is discovered at the end, not presupposed as “you are the enemy.”

LRR on each: forward crawl to Logic/Reason fail or charge resolved. That is the **logical endpoint**.

## Meet (after endpoints)

```text
if empty meet under the lock → debate
if complementary / open join → synthesis
if synonym / specialization → no clone (never ran)
antithesis / battle / majority → refuse (that is twin gutter)
```

Seeing sibling pads **before** endpoint is not a parallel-reasoning pattern. It is MAD/interactive PR. We already measured that FS logs can leak; bypass, don’t call it the gait.
